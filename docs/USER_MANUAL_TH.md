# คู่มือการใช้งานระบบจัดการห้องสมุด

เอกสารฉบับนี้อธิบายการใช้งานระบบสำหรับสมาชิก ผู้ดูแลระบบ และผู้ติดตั้งระบบ

## 1. ภาพรวมระบบ

ระบบจัดการห้องสมุดรองรับงานสำคัญดังต่อไปนี้

- สมัครสมาชิก เข้าสู่ระบบ และจัดการโปรไฟล์
- ค้นหาและกรองหนังสือตามชื่อ ผู้แต่ง และหมวดหมู่
- ยืมหนังสือและตรวจสอบประวัติการยืม
- จัดการหนังสือ หมวดหมู่ รูปปก และจำนวนคงเหลือ
- บันทึกการคืนและติดตามรายการเกินกำหนด
- แจ้งเตือนหนังสือใกล้หมดและหนังสือเกินกำหนดผ่านอีเมล
- แสดงประวัติการแจ้งเตือน
- แสดงรายงาน ดาวน์โหลด CSV และพิมพ์เป็น PDF
- สำรองข้อมูลอัตโนมัติและด้วยคำสั่ง

## 2. ประเภทผู้ใช้งาน

### สมาชิกทั่วไป (`user`)

สมาชิกสามารถค้นหาหนังสือ ดูรายละเอียด ยืมหนังสือ ตรวจสอบรายการยืม และแก้ไขข้อมูลส่วนตัวได้

### ผู้ดูแลระบบ (`admin`)

ผู้ดูแลสามารถใช้งานทุกส่วนของสมาชิก รวมถึงเพิ่ม แก้ไข และลบหนังสือ จัดการหมวดหมู่ บันทึกการคืน ดูรายงาน ตั้งค่าการแจ้งเตือน และตรวจสอบประวัติการแจ้งเตือนได้

## 3. การเข้าสู่ระบบ

1. เปิดหน้าแรกของระบบ
2. กด **เข้าสู่ระบบ**
3. กรอกอีเมลและรหัสผ่าน
4. กด **เข้าสู่ระบบ**

หากยังไม่มีบัญชี ให้กด **สมัครสมาชิก** และกรอกชื่อ อีเมล และรหัสผ่าน ระบบจะกำหนดสิทธิ์เป็นสมาชิกทั่วไปโดยอัตโนมัติ

หากลืมรหัสผ่าน ให้กด **ลืมรหัสผ่าน** แล้วปฏิบัติตามข้อความที่ส่งไปยังอีเมล

> บัญชีผู้ดูแลเริ่มต้นจาก Seeder คือ `admin@example.com` รหัสผ่าน `password` ควรเปลี่ยนทันทีหลังเข้าสู่ระบบ

## 4. การใช้งานสำหรับสมาชิก

### 4.1 ค้นหาหนังสือ

1. เลือกเมนู **หนังสือ**
2. พิมพ์ชื่อหนังสือหรือชื่อผู้แต่งในช่องค้นหา
3. เลือกหมวดหมู่ หากต้องการจำกัดผลลัพธ์
4. กดค้นหา แล้วเลือกหนังสือที่ต้องการดูรายละเอียด

### 4.2 ยืมหนังสือ

1. เปิดหน้ารายละเอียดหนังสือ
2. ตรวจสอบสถานะคงเหลือ
3. กด **ส่งคำขอยืมหนังสือ**
4. คำขอจะแสดงสถานะ **รออนุมัติ** โดยจำนวนหนังสือยังไม่ลดลง
   ระบบจะสร้างการแจ้งเตือนให้ผู้ดูแลทุกคนเพื่อเข้ามาตรวจสอบคำขอ
5. เมื่อผู้ดูแลอนุมัติ ระบบจะลดจำนวนคงเหลือและกำหนดวันคืนให้อัตโนมัติ 14 วันนับจากวันที่อนุมัติ

สมาชิกไม่สามารถส่งคำขอหนังสือเล่มเดิมซ้ำขณะที่คำขอยังรออนุมัติหรือยังไม่ได้คืน และไม่สามารถส่งคำขอหนังสือที่คงเหลือเป็นศูนย์

### 4.3 ตรวจสอบรายการยืม

เลือกเมนู **รายการยืมของฉัน** เพื่อดูสถานะรออนุมัติ ไม่อนุมัติ กำลังยืม เกินกำหนด หรือคืนแล้ว รวมถึงวันที่ยืม วันครบกำหนด และวันที่คืน

การคืนหนังสือต้องนำหนังสือให้เจ้าหน้าที่ จากนั้นผู้ดูแลจะบันทึกการคืนในระบบ

### 4.4 จัดการโปรไฟล์

1. กดชื่อผู้ใช้บริเวณมุมขวาบน
2. เลือก **โปรไฟล์**
3. แก้ไขชื่อ อีเมล หรือรหัสผ่าน

บัญชีที่ยังมีรายการยืมค้างอยู่จะไม่สามารถลบบัญชีได้

## 5. การใช้งานสำหรับผู้ดูแล

### 5.1 แดชบอร์ดผู้ดูแล

แดชบอร์ดแสดงจำนวนหนังสือ หนังสือพร้อมยืม รายการกำลังยืม รายการเกินกำหนด สมาชิก หมวดหมู่ หนังสือใกล้หมด และกิจกรรมล่าสุด

### 5.2 เพิ่มหนังสือ

1. เลือก **หนังสือ** แล้วกด **เพิ่มหนังสือ**
2. กรอกชื่อหนังสือ ผู้แต่ง หมวดหมู่ จำนวนคงเหลือ และรายละเอียด
3. เลือกรูปปก หากต้องการ
4. กด **บันทึก**

รูปปกรองรับไฟล์ JPG, JPEG, PNG และ WebP ขนาดไม่เกิน 2 MB

### 5.3 แก้ไขหรือลบหนังสือ

- กด **แก้ไข** เพื่อเปลี่ยนข้อมูล จำนวนคงเหลือ หรือรูปปก
- สามารถเลือก **ลบรูปปกปัจจุบัน** ได้
- เมื่ออัปโหลดรูปใหม่ ระบบจะลบไฟล์รูปเดิมอัตโนมัติ
- หนังสือที่มีประวัติการยืมจะไม่สามารถลบได้ เพื่อรักษาความถูกต้องของข้อมูล

### 5.4 จัดการหมวดหมู่

เลือกเมนู **หมวดหมู่** เพื่อเพิ่ม แก้ไข หรือลบหมวดหมู่ หมวดหมู่ที่ยังมีหนังสืออยู่จะไม่สามารถลบได้

### 5.5 อนุมัติหรือปฏิเสธคำขอยืม

1. เลือกเมนู **รายการยืม–คืน**
2. ค้นหารายการที่มีสถานะ **รออนุมัติ**
3. กด **อนุมัติ** เพื่อเริ่มการยืมและกำหนดวันคืน 14 วัน หรือกด **ปฏิเสธ** เพื่อสิ้นสุดคำขอ

ระบบจะลดจำนวนหนังสือเมื่ออนุมัติเท่านั้น หากหนังสือหมดก่อนดำเนินการ ระบบจะไม่อนุญาตให้อนุมัติคำขอนั้น

### 5.6 บันทึกการคืน

1. เลือกเมนู **รายการยืม–คืน**
2. ค้นหารายการที่ต้องการ
3. กด **บันทึกการคืน**

ระบบจะเปลี่ยนสถานะเป็นคืนแล้ว บันทึกวันที่คืน และเพิ่มจำนวนหนังสือกลับเข้าคลัง การกดคืนรายการเดิมซ้ำจะไม่เพิ่มจำนวนหนังสืออีก

### 5.6 ตั้งค่าหนังสือใกล้หมด

1. กดชื่อผู้ดูแล แล้วเลือก **ตั้งค่าระบบ**
2. ระบุจำนวนหนังสือที่ถือว่าใกล้หมด
3. กด **บันทึกการตั้งค่า**

เมื่อจำนวนหนังสือลดผ่านเกณฑ์ ระบบจะจัดคิวส่งอีเมลถึงผู้ดูแลทุกคนและบันทึกประวัติการแจ้งเตือน

### 5.7 ทดสอบอีเมล

ในหน้า **ตั้งค่าระบบ** กด **ส่งอีเมลทดสอบ** ระบบจะจัดคิวส่งอีเมลไปยังอีเมลของผู้ดูแลที่กำลังเข้าสู่ระบบ

หากไม่ได้รับอีเมล ให้ตรวจค่า SMTP และตรวจว่า Queue Worker กำลังทำงาน

### 5.8 ประวัติการแจ้งเตือน

กดชื่อผู้ดูแล แล้วเลือก **การแจ้งเตือน** เพื่อดูข้อความแจ้งหนังสือใกล้หมดและรายการเกินกำหนด สามารถกด **อ่านทั้งหมด** เพื่อทำเครื่องหมายรายการทั้งหมดว่าอ่านแล้ว

### 5.9 รายงาน

กดชื่อผู้ดูแล แล้วเลือก **รายงาน** ระบบจะแสดงสถิติภาพรวมและหนังสือยอดนิยม

- กด **ดาวน์โหลด CSV / Excel** เพื่อดาวน์โหลดข้อมูลที่เปิดด้วย Microsoft Excel หรือ Google Sheets ได้
- กด **พิมพ์ / บันทึก PDF** แล้วเลือกเครื่องพิมพ์ `Save as PDF` ในหน้าต่างพิมพ์ของเบราว์เซอร์

## 6. ระบบแจ้งเตือนอัตโนมัติ

ระบบตรวจรายการเกินกำหนดทุกวันเวลา 08:00 น. ตามเวลา Asia/Bangkok รายการที่เพิ่งเกินกำหนดจะถูกเปลี่ยนสถานะและจัดคิวส่งอีเมลให้สมาชิกเพียงครั้งเดียว

ผู้ดูแลต้องเปิด Queue Worker และ Scheduler Worker เพื่อให้ระบบอัตโนมัติทำงาน

```powershell
composer queue:work
```

```powershell
composer schedule:work
```

## 7. การสำรองข้อมูล

ระบบสร้างไฟล์สำรองทุกวันเวลา 02:00 น. และเก็บย้อนหลังตามจำนวนวันที่กำหนด ค่าเริ่มต้นคือ 14 วัน

สำรองข้อมูลทันทีด้วยคำสั่ง:

```powershell
composer backup:database
```

ไฟล์สำรองจะอยู่ใน `storage/app/private/backups` และเป็นไฟล์ JSON ที่บีบอัดด้วย Gzip ควรคัดลอกไฟล์สำรองออกไปเก็บในพื้นที่อื่นเป็นระยะ

## 8. การติดตั้งสำหรับการพัฒนา

ต้องติดตั้ง PHP, Composer, Node.js และส่วนขยายฐานข้อมูลที่ Laravel ต้องใช้

```powershell
composer install
Copy-Item .env.example .env
php artisan key:generate
php artisan migrate --seed
npm install
npm run build
php artisan storage:link
php artisan serve
```

เปิดระบบที่ `http://127.0.0.1:8000`

## 9. การเตรียม Production

1. คัดลอก `.env.production.example` เป็น `.env`
2. กำหนด `APP_KEY`, `APP_URL`, ฐานข้อมูล และ SMTP
3. ตรวจว่า `APP_ENV=production` และ `APP_DEBUG=false`
4. เปิด HTTPS และกำหนด `SESSION_SECURE_COOKIE=true`
5. ให้ Web Server เขียน `storage` และ `bootstrap/cache` ได้
6. รันคำสั่งต่อไปนี้

```powershell
composer install --no-dev --optimize-autoloader
php artisan storage:link
composer deploy:optimize
```

7. ตั้ง Queue Worker และ Scheduler Worker ให้เริ่มใหม่อัตโนมัติเมื่อเครื่องรีสตาร์ต

ไม่ควรเก็บรหัสผ่านหรือ Production `.env` ไว้ใน Git

## 10. การตรวจสอบระบบ

รันชุดทดสอบ:

```powershell
php artisan test --compact
```

สร้าง Frontend production build:

```powershell
npm run build
```

ตรวจตารางเวลาอัตโนมัติ:

```powershell
php artisan schedule:list
```

ตรวจ Queue ที่ล้มเหลว:

```powershell
php artisan queue:failed
```

## 11. การแก้ปัญหาที่พบบ่อย

### หน้าเว็บไม่แสดง CSS หรือรูปแบบล่าสุด

```powershell
npm run build
php artisan optimize:clear
```

### หน้าเพิ่มหนังสือแสดง 404

```powershell
php artisan optimize:clear
```

จากนั้นหยุด `php artisan serve` ด้วย `Ctrl+C` แล้วเปิดเซิร์ฟเวอร์ใหม่

### รูปปกไม่แสดง

```powershell
php artisan storage:link
```

ตรวจว่าโฟลเดอร์ `storage/app/public` สามารถเขียนได้

### อีเมลไม่ถูกส่ง

- ตรวจค่า `MAIL_*` ใน `.env`
- เปิด Queue Worker ด้วย `composer queue:work`
- ตรวจรายการล้มเหลวด้วย `php artisan queue:failed`
- ใช้ปุ่มส่งอีเมลทดสอบในหน้าตั้งค่าระบบ

### งานตามเวลาไม่ทำงาน

- เปิด `composer schedule:work`
- ตรวจด้วย `php artisan schedule:list`
- บน Production สามารถใช้ Cron เรียก `php artisan schedule:run` ทุกนาทีแทนได้

### ต้องการสร้างผู้ดูแลเริ่มต้น

```powershell
php artisan db:seed --class=DatabaseSeeder --no-interaction
```

จากนั้นเข้าสู่ระบบด้วย `admin@example.com` / `password` และเปลี่ยนรหัสผ่านทันที

## 12. ข้อควรระวัง

- ห้ามปิด Queue Worker หากต้องการส่งอีเมล
- ห้ามปิด Scheduler หากต้องการแจ้งเกินกำหนดและสำรองข้อมูลอัตโนมัติ
- สำรองฐานข้อมูลก่อน migration หรือเปลี่ยนแปลงข้อมูลจำนวนมาก
- ห้ามเปิด `APP_DEBUG=true` บน Production
- เปลี่ยนรหัสผ่านบัญชีตัวอย่างก่อนเปิดให้ใช้งานจริง
